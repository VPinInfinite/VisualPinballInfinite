SMAA's lookup pictures (AreaTex and SearchTex), from Visual Pinball X build 5436's
src/renderer/AreaTex.h and SearchTex.h (commit af26b2d), as raw bytes:

  area.bin    160 x 560 texels, two bytes each (red, green)
  search.bin  64 x 16 texels, one byte each
