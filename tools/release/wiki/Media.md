# Media

A table's media are what a front end shows while you browse: its playfield picture or video, backglass, score display, topper, wheel (its logo), flyer and instruction card. The app shows them on tiles, on table pages and in cabinet mode. A PinUP pack is different: it plays during the game. See [PinUP packs](PinUP-packs).

## Where they come from

- **VPS's pictures,** fetched once and kept on your PC.
- **PinUP Popper's media folders,** if you use Popper: its pictures and videos for each game. Popper's playfield media made for a cabinet often lie on their side; the app shows them upright. Copies Popper keeps twice show once.
- **The app's own player,** which makes them for you: see below.
- **PinballX's and PinballY's media folders,** where either plays your library's tables: their pictures and videos for each game, named as their game lists name it.
- **What you drop in:** pictures and videos dropped with a table, or onto its row in Tools › Media, go into your front end's media folders for it: PinUP Popper's, else PinballX's, else PinballY's. With more than one, Tools › Media › **Media you drop in go in** chooses.

## Making media

**Make its media…** on a table's page (or **Make media with our player…** in its **…** menu) has the app's own player make them, with no window:

- **Its playfield,** seen from straight above and cut to the playfield: a picture, and a 20-second preview video of a game starting, with the table's sound in it.
- **Its backglass,** drawn from the table's backglass file, and **its score display**, for tables that have them.
- **Its wheel,** a logo the app draws for it.

Tick what to make; what you don't tick stays as it is. It takes about a minute a table with the video, and asks before replacing media it made before. Media from VPS and PinUP Popper are never touched.

## Media for every table

Tools › Media lists every table's media, kind by kind, with empty squares for what's lacking. **Which tables show** picks all of them, those missing some, or those complete. Toppers, flyers and instruction cards come from VPS or PinUP Popper, so a table counts as complete without them.

**Make missing media for all tables** makes what's missing, one table at a time in the background, and says first how long it will take. The bar at the top of the app shows how far it's got, and what's waiting its turn.

## Choosing which one shows

Where a kind has several, open its stack on the table's page and pick **Show this one**. The one with the blue check shows on its tile, its page and in cabinet mode.

## Turning a picture

Right-click a picture or video on a table's page to turn it a quarter right or left. The app remembers the turn; the file stays as it is.

## Media for PinUP Popper

PinUP Popper shows the pictures and videos kept in its own folders, so it doesn't see VPS's or the ones the app makes unless they're copied over. Tools › Media › PinUP Popper › **Show the same media in PinUP Popper** does that. When it's on:

- The one with the blue check of each kind (playfield picture or video, backglass, score display, wheel) is copied into Popper's folder for that screen, named for Popper's name for the game, whenever you choose another, so Popper shows the same one.
- Media you make go in where Popper has none.
- The one Popper had there is kept beside it, numbered (`Name01.png`), never deleted, so choosing it again swaps them back.
- VPS's pictures go in as PNGs.

**Put them in for every table now** does it for every table at once, saying first how many would go in. Turned off, Popper's folders are left alone, though a picture's own window can still copy that one over on your word.

## Media for PinballX and PinballY

Where PinballX or PinballY plays your library's tables, Tools › Media shows where their media are, and offers **Put the media a table uses in PinballX's folders too** (or PinballY's, or both): the same as for Popper, in each screen's folder, named for the game as their game lists name it. The one there before is kept beside it, numbered (`Name 1.png`). **Put them in for every table now** does it for every table at once. If either is installed somewhere unusual, its folder can be set in the settings (`[VPI]` `PinballXFolder`, `PinballYFolder`).
