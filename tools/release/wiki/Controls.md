# Controls

Out of the box, the keys and buttons are VPX's own, so they work as they do in VPX. Settings › Controls lists every game action with its keys and buttons, the keyboard's and the controllers' apart. Click an action and press a key or button to put it there. The page lights each action as you press it, so it's also a live test of every button, stick and plunger. **Save** keeps your changes; **Undo changes** puts them back.

## The keyboard

| Action | Key |
|---|---|
| Left flipper | Left **Shift** |
| Right flipper | Right **Shift** |
| Staged flippers, on tables that have them | the same **Shift** keys |
| Left magna-save | Left **Ctrl** |
| Right magna-save | Right **Ctrl** |
| Launch the ball (the plunger) | **Enter**: hold to pull, let go to launch |
| Start a game | **1** |
| Add a coin | **5**, **4**, **3** or **6** (the four coin slots) |
| Extra ball (buy-in) | **B** |
| Nudge from the left | **Z** |
| Nudge from the right | **/** |
| Nudge from the front | **Space** |
| Tilt (the cabinet's tilt bob) | **T** |
| Slam tilt | **Home** |
| The lockbar's button | Left **Alt** |
| Open or close the coin door | **End** |
| The coin door's service buttons, for a machine's operator menu | **7**, **8**, **9**, **0**, then **6**, **Page Up**, **-** |
| Reset the machine | **F3** |
| Volume down, volume up | **-**, **=** |
| Screenshot | **F12** |
| The pause menu | **P** |
| The pause menu, with Quit the table picked | **Esc** or **Q** |

As in VPX, **6** is both the fourth coin slot and the fifth service button, and **-** both the seventh service button and volume down.

## Gamepads

Any gamepad Windows knows works as soon as it's connected, in VPX's layout for gamepads. The buttons are named as on an Xbox controller; on others, it's the button in the same place.

| Control | Does |
|---|---|
| Left trigger | the left flipper; pressed further, its staged flipper too |
| Right trigger | the right flipper; pressed further, its staged flipper too |
| Left shoulder button | the left magna-save |
| Right shoulder button | the right magna-save |
| **A** | launch the ball |
| **B** | start a game |
| **Y** | add a coin |
| The d-pad: left, down, up, right | the coin door's service buttons 1 to 4 |
| **Back** | the pause menu |
| Left stick | nudge |
| Right stick, down and up | pull and release the plunger |

**X** and the gamepad's own **Start** do nothing until you give them an action. A gamepad rumbles where VPX's gamepads rumble.

## In the pause menu

| To | Keyboard | Gamepad or cabinet |
|---|---|---|
| Move up and down | **↑** **↓** | the magna-saves |
| Change a setting | **←** **→** | the flippers |
| Choose | **Enter** or **Space** | **Start**, or the launch button |
| Go back | **Esc** or **Backspace** | |
| Play on | **P** or **Esc** | **Back** |

The mouse works too: point and click.

## Cabinet boards

- **Pinscape:** its nudge sensor and its plunger are read as soon as it's plugged in. Its buttons send the keys Pinscape's own setup gives them, usually VPX's, as above.
- **Open Pinball Device boards:** their standard pinball buttons go to the matching actions: the flippers and staged flippers, the magna-saves, start, the four coins, launch, the lockbar, tilt and slam tilt, the coin door and its first four service buttons, the three nudges, and the volume. Their plunger and nudge are read as VPX reads them.
- **Key encoders:** boards that type keys work as a keyboard; their keys are the ones above unless you change them here.
- **Other boards** that Windows sees as a joystick: put their buttons on actions here.

## Nudging

Nudge sensors (a cabinet board's accelerometer, or a gamepad's left stick) are read as VPX reads them: a cabinet's sensor smoothed and calibrated, so the table feels the real cabinet move. The nudge keys push the table as VPX's do. Too hard, and the tilt bob swings far enough to tilt the game, as on a real machine.

## Plungers

An analog plunger (a cabinet board's, or a gamepad's right stick) works through VPX's own handling, so pulling and letting go feels as in VPX. Without one, **Enter** pulls the plunger while you hold it.

## More sensors

Further nudge and plunger sensors, under VPX's own setting names, are on Settings › Advanced.
